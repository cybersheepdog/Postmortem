# postmortem - dependencies
# ============================================================================
# Python 3.10+ and one required package (below). Beyond psutil, the analyzer
# runs on the standard library alone: scanning .eml files, ingesting MBOX,
# exporting HTML/JSON/CSV/IOC reports, and parsing a Microsoft 365 Unified
# Audit Log all work with nothing else installed.
#
# Everything under "Optional" degrades gracefully when absent.
# Uncomment what you need.

# --- Required ---------------------------------------------------------------
psutil                  # runtime CPU/RAM detection; sizes every parallel phase
                        # to the host instead of a hard-coded worker count

# --- Optional: parsing correctness / robustness -----------------------------
# beautifulsoup4        # more robust HTML body/link/form parsing than regex
# tldextract            # Public Suffix List-aware registrable-domain parsing

# --- Optional: attachment / image analysis ----------------------------------
# yara-python           # --yara-rules: scan attachments with YARA
# pyzbar                # --scan-qr: decode QR codes (also needs Pillow + libzbar)
# Pillow                # --scan-qr: image loading
# py7zr                 # peek inside .7z archive attachments
# rarfile               # peek inside .rar archive attachments

# --- Optional: geolocation (offline, needs local GeoLite2 .mmdb files) -------
# maxminddb             # --geoip-db: read MaxMind GeoLite2 City/Country/ASN

# --- Optional: Outlook PST/OST ingestion ------------------------------------
# libpff-python         # read .pst / .ost containers directly

# --- Optional: development / testing ----------------------------------------
# pytest>=7.0
# pyflakes>=3.0
